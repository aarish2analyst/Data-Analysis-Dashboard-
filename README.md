# Vishal Store Data Analysis(Interactive dashboard creation using MS Excel)
## Project Objective
To create annual sales report of Vishal store for year 2022, so that we can understand the customers and grow sales in upcoming years

## Qusetionns (KPIs)
- Compare the sales and order using single chart
- which month got the highest sales and orders?
- Who purchased more men or women?
- What aredifferent order status in 2022?
- List top 10 states contributing to the sales
- Relation betwwn age and gender based on number of ordres
- Which channel is cintributing maximum to the sales?
- Highest selling category
- Percentage of total orders delivered

  ## Process
  - Verify data for any missing, duplicate values and sort it out
  - Made  sure data  is consistent and clean with data type, data format and values used
  - created pivot tables according to KPIs
  - Merged all pivot tables into dashboard and applied slicer to make it dynamic

    ## Project Insight
    - Women customers are more likely to buy produvts than men (~65%)
    - Maharashtra, Karnatka and Uttarpradesh are the top 3 buyers
    - The adult age group(30-49 years) is contributing max to  the sales approx 50%
    - The channel from where customers are ordering maximum are amazon, flipkart and myntra
    - More than 90% of the products are delivered
 
      ## Final conclusion
      To improve the sales of Visahl store a strategic marketing plan focusing on women aged 30-49 years living in Maharastra, Karnatka and Uttar Pradesh should  be implememnted.The approach should include argeted digitalmarketing campaigns and personalised promotions to grab their attentions.
